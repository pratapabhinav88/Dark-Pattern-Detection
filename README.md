# Dark-Pattern-Detection
Dark patterns is deceptive design techniques that manipulate user behavior to benefit service providers, pose significant challenges to consumer rights, privacy, and fair-trade practices. Recognizing the harm caused by these practices, the Indian government seeks to foster collaboration among stakeholders to create a safer digital environment. 

## The Solution which is provided is - Hawk's Detector 
Hawk’s Detector is a browser extension which works on different web browsers to scan websites for hidden traps and manipulative plans behind the pixels. Dark Pattern is a term used in user experience (UX) design to describe elements that intentionally mislead, deceive, or trick users into taking actions they might not have taken otherwise. let's take an example if we are searching for shoes then many times it shows 5 left, 30 mins left for the offer, 500 bought in 1 day, etc so this is a manipulative plans.

### There are several types of dark patterns like Countdown, Scarcity, Social Proof , Forced Continuity, Disguised Ads, Confirm Shaming, Hidden Cost, Misdirection, etc
### We utilized skills in HTML, CSS, JavaScript, DOM, Regex, and browser extension development.

#### HTML (Hypertext Markup Language): Hawk’s Detector, HTML was used to create the interface of the browser extension, organizing various components such as buttons, text, and layout structure, ensuring an accessible and user-friendly experience.
#### CSS (Cascading Style Sheets): CSS is essential for styling the web page elements defined in HTML, allowing us to control colors, fonts, spacing, and overall design aesthetics. CSS was used to style our extension interface, making it visually appealing, intuitive, and easy to navigate for users.
#### JavaScript: In Hawk’s Detector, JavaScript powered the core functionality, handling logic for detecting dark patterns in real-time, responding to user actions, and enabling communication between different components of the extension.
#### DOM (Document Object Model) Manipulation: The DOM represents the structure of a web page and allows scripts to dynamically update content. Through DOM , Hawk’s Detector could interact with live web pages, scanning elements in real-time to identify patterns or manipulative plans and display results to users as they browse.
#### Regex (Regular Expressions): Regex is a tool for searching and pattern matching within strings. In our project, Regex played a crucial role in scanning text and identifying common deceptive patterns (like hidden fees or disguised ads). Regex enabled quick, efficient text analysis, which was essential for spotting subtle dark patterns within web content.

#### Browser Extension Development: Developing a browser extension requires knowledge of specific APIs and practices to integrate with web browsers. This skill enabled us to build an application that works seamlessly across multiple browsers, providing users with a consistent experience and maintaining compatibility with various browsing environments. It also allowed us to implement features like real-time scanning, background processing, and user notifications.

### It’s key features are Pattern Recognition, Transparent Reporting, User Friendly, Real-time Analysis, Continuous Learning

### Conclusion: Hawk's Detector is champions transparency and integrity in the digital landscape by exposing dark patterns and empowering users with clear insights. Our mission is to set new standards against deceptive practices, paving the way for a trusted and ethical online experience where users are informed and empowered.
